## Technical Deep Dive

### Gradient Checking Mathematics

**Numerical Gradient** (Finite Difference Approximation):
```
f'(x) ≈ [f(x + ε) - f(x - ε)] / (2ε)
```

**Why This Works**:
- Based on definition of derivative
- Two-point central difference
- O(ε²) accuracy (very good!)

**Implementation**:
```c
float compute_numerical_gradient(float* param_data, int param_idx, ...) {
    float original = param_data[param_idx];

    param_data[param_idx] = original + EPSILON;
    float loss_plus = loss_fn(param_data, context);

    param_data[param_idx] = original - EPSILON;
    float loss_minus = loss_fn(param_data, context);

    param_data[param_idx] = original;  // Restore

    return (loss_plus - loss_minus) / (2.0f * EPSILON);
}
```

**Analytical Gradient** (From Backward Pass):
```
Computed by tl_graph_backward() using chain rule
```

**Comparison** (Relative Error):
```
relative_error = |analytical - numerical| / max(|analytical|, |numerical|)
```

### Float Precision Analysis

**Float Precision**: ~7 decimal digits
**Double Precision**: ~15 decimal digits

**Example from our tests**:

With float (epsilon=1e-5):
```
loss_plus  = 10.7000026703  (expected: 10.7000020)
loss_minus = 10.6999979019  (expected: 10.6999980)
difference = 0.0000047684   (expected: 0.0000040)
numerical  = 0.2384185791   (expected: 0.2000000)
error      = 19.2%          (LARGE!)
```

With double (epsilon=1e-7):
```
loss_plus  = 10.700000200000... (much more accurate)
loss_minus = 10.699999800000... (much more accurate)
difference = 0.000000400000...  (accurate)
numerical  = 0.200000000...     (accurate)
error      = 3.53e-08           (TINY!)
```

**Conclusion**: Float arithmetic accumulates ~1e-6 errors, which become 10-20% errors when divided by 2ε (where ε=1e-5).

### Xavier Weight Initialization

**Formula**:
```
scale = sqrt(2.0 / (fan_in + fan_out))
weights ~ Uniform[-scale, +scale]
```

**Why This Works**:
- Maintains variance across layers
- Prevents vanishing/exploding gradients at initialization
- fan_in: number of inputs to neuron
- fan_out: number of outputs from neuron

**Implementation**:
```c
void init_weights_xavier(float* data, int fan_in, int fan_out) {
    float scale = sqrtf(2.0f / (fan_in + fan_out));
    for (int i = 0; i < fan_in * fan_out; i++) {
        data[i] = ((float)rand() / RAND_MAX * 2.0f - 1.0f) * scale;
    }
}
```

### Residual Networks (ResNets)

**Architecture**:
```
x → [F(x)] → F(x) + x → output
    \_________/     ↑
    residual      skip
    block     connection
```

**Gradient Flow**:
```
∂L/∂x = ∂L/∂output * (∂F/∂x + 1)
                         ↑       ↑
                      residual  skip
```

**Key Benefit**: Skip connection provides direct gradient path, mitigating vanishing gradients.

### Deep Networks

**Challenge**: Gradients diminish exponentially with depth

**Example** (10 layers):
```
∂L/∂x = ∂L/∂y₁₀ * ∂y₁₀/∂y₉ * ... * ∂y₂/∂y₁ * ∂y₁/∂x
        \_______________chain of 10 derivatives________________/
```

If each derivative ≈ 0.5, final gradient ≈ (0.5)¹⁰ ≈ 0.001 (vanishing!)

**Solution Strategies**:
- ReLU activation (gradient = 1 for positive inputs)
- Skip connections (ResNets)
- Batch normalization (not yet implemented in Tofu)
- Careful weight initialization (Xavier)
